# АвтоФинансы — Native Android App

Приложение для учета финансов автосервиса, разработанное на **Kotlin** и **Jetpack Compose**.

## Основные возможности

- **Учёт доходов и расходов**: Быстрый ввод прибыли, расходников и должников.
- **Поиск должников и списание**: Удобная карточка должников с возможностью полного или частичного списания.
- **Учёт зарплат сотрудников**: Фиксация окладов, выплат и остатков к выплате.
- **Голосовое управление**: Поддержка распознавания голосовых команд на русском языке с помощью сэмплера речи Android и умного парсера команд.
- **Финансовые отчёты**: Фильтрация за день, неделю, месяц и за всё время, с возможностью экспорта в CSV.
- **Персонализация**: Выбор из 5 цветовых тем оформления (Синяя, Изумрудная, Фиолетовая, Оранжевая, Красная).
- **Локальная база данных**: Работает через **Room Database** без необходимости постоянно быть в сети.

## Технологии

- **Язык**: Kotlin
- **UI Framework**: Jetpack Compose (Material 3)
- **Архитектура**: MVVM (Model-View-ViewModel) + Coroutines & Flow
- **База данных**: Room Persistence Library (KSP)
- **Иконка**: Custom Adaptive App Icon
